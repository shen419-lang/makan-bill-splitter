# Makan Bill Splitter 🍽️

Split restaurant bills in Malaysia with friends.

## Features
- Equal split, or split by what each person ate
- Service charge: 0%, 5%, 10% or custom
- SST 6% (food) or 8% (alcohol)
- Bank Negara 5 sen rounding
- Copy the split straight to WhatsApp

Built by Ethan while learning vibe coding.
